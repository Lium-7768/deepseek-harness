# @deepseek-ai/dsh-client-ui-shared

[English](README.md) | 中文

供桌面 Web 客户端和原生移动客户端共用的展示类型、主题 token 与纯事件投影辅助函数。该包对用户、助手和工具事件分类，过滤协议流量与内部提示，合并助手流式分片，派生紧凑的工具状态，并将展示文本切分为正文与围栏代码片段。

## 模型体验

### 会话事件投影

#### 模型可见内容

`projectVisibleMessages()` 不会进入模型请求；它只投影桌面运行时已经持久化的记录。

#### Token 影响

无；投影不会向提供方请求新增或删除内容。

#### KV 缓存影响

无；该包不修改提供方请求顺序或缓存的提示内容。

## 已知限制与延后工作

- **事件分类有意面向投影** —— 它接受已知的桌面事件记录，而不定义公开的线协议；新的持久事件类别必须在客户端渲染前作出明确可见性决定并补充测试。
- **消息分段只识别围栏代码** —— Markdown 布局、语法高亮和富附件仍由各客户端负责渲染。
- **主题 token 提供共享语义基线** —— 平台专属的无障碍、安全区、字体排印和层级行为仍由各客户端负责。
