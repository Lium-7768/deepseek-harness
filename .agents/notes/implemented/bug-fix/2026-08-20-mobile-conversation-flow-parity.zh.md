# Agent Note: 原生移动端对话流对齐

Status: implemented

[English](2026-08-20-mobile-conversation-flow-parity.md) | 中文

## Problem

原生会话页把桌面对话时间线压缩为用户气泡、助手 Markdown 和通用工具卡片。它丢失了助手推理块、模型重试披露、回合错误、真实工具名、关联工具结果以及回合级运行尾部。因此，桌面将 `Think`、`Tool call · bash`、重试失败详情和 `Deep diving...` 显示为独立行时，手机可能反复显示“工具 / 暂无输出摘要”卡片。紧凑统计栏还可能暴露 `132.0146174218317 tok/s` 这样的未限定 JavaScript 浮点结果，而原始事件轨迹标签无法告诉读者哪项操作正在运行或是否成功。

## Decision

`projectNativeConversationRows()` 直接从移动 Gateway 已返回的桌面持久会话事件派生有序原生显示行。它保留 `user/message`、推流中的 `assistant/chunk` 推理与正文增量、已完成助手的 `reasoning` 与 `text` 块、关联的 `tool/call` 和 `tool/result` 生命周期记录、`llm/retry` 与 `turn/error`。流式增量按桌面回合、步骤、块序号和类别合并；最终助手消息替换同一步骤的临时行。该投影用关联结果更新工具调用行，保留源序号供附件使用，并为每个实时块分配 `stream:<turn>:<step>:<kind>:<index>` 键，避免 React Native 在文本增长时重挂载该行。

主原生会话以独立 React Native 组件渲染这些行类别。助手正文继续使用紧凑的共享移动端 `NativeMarkdown` 正文字号；推理使用可展开的 `Think` 披露行；工具调用使用带状态点和可展开 IN/OUT 详情的紧凑 `Tool call · <name>` 行；模型重试显示与桌面等价的延迟和失败原因；回合错误保持为提示；打开的持久回合在对话下方独立的原生运行状态槽中显示 `Deep diving...`，避免被 `FlatList` 视口裁切。可见的 Think、活动目标和通用工具行分别使用桌面 `ic_ds_think_outline_14`、`ic_ds_goal_outline_16` 和 `sparkle_16` SVG 路径。工具输入和输出使用限高嵌套阅读面，长围栏代码或 JSON 默认限制为 16 行并提供显式展开控件。读者离开最新消息后，列表停止跟随流式内容并显示仅图标的返回最新消息控件。

原生渲染器不复刻桌面 DOM、CSS、拖拽行为或检查面板。它将桌面持久信息及层级映射为满足触控尺寸的原生控件，同时保留系统文本选择、可访问性角色、安全区域布局和现有原生编辑器。

`formatStatisticsTokensPerSecond()` 使用桌面对话的解码吞吐规则：每秒十个 token 及以上取整，小于十个 token 保留一位小数。因此统计栏显示 `132 tok/s` 而不是内部浮点商，同时保留桌面的指标顺序、时长格式、缓存比例和紧凑 token 单位。

`projectNativeTrajectoryActivities()` 将同一组移动 Gateway 持久事件映射为原生活动账本，而非渲染线路事件名。它隐藏传输增量和回合分隔符，将每回合的首个活动归属到 `第 n 轮`，按 `callId` 关联 `tool/call` 与 `tool/result`，并输出中文操作标签、状态、受限结果预览和已知耗时。用户消息、推理、回复、上下文加载、压缩、重试、失败和问题仍是彼此独立的活动。工具标题将 `运行命令` 或 `读取文件` 等用户可读动作与桌面工具标识配对，因此手机能同时解释意图和来源。

工作区仅在 SecureStore 中保存设备绑定的 `{ gatewayUrl, deviceId, sessionId }` 选择记录。原生应用重载后，只有当前已配对桌面的会话列表同时确认设备和会话仍存在时才恢复该标识；更换桌面连接、忘记设备、归档会话或删除会话都会清除本地记录。该记录不包含访问令牌或复制的会话内容。工作区以紧凑的当前会话选择器和桌面更新标签替换大尺寸营销首屏；设置页使用满足触控尺寸的分隔行而非叠放卡片。可见的模型、插件、预设、文件夹和新建项目图标均采用桌面共享 SVG 的精确路径。

原生根布局会在挂载深链接页面前一次性完成受保护连接恢复，避免路由短暂进入错误的未连接状态。根 Drawer 显式声明所有嵌套路由。会话和工作区重命名页使用仅图标的原生返回操作，并通过正常导航接收已知桌面标题以立即预填。`NativeListRow` 为语义选择项提供多行模式；权限选项使用稳定键，智能体模式说明不再截断。Markdown 行、行内代码和助手容器可收缩，并在安全标点处换行；长会话统计改为两行而非单行省略号。模型行会隐藏等价的显示名称和模型 ID 重复内容；设置页视觉上缩写长设备标识但保留完整无障碍标签；即使模拟器相机预览为空，二维码扫描页也会显示高对比取景框和放置提示。

## Verification

移动端严格 TypeScript 程序通过。原生对话投影测试覆盖有序的用户正文、Think、助手文本、关联的失败工具输出、重试元数据、回合错误、活动回合时间、推流中的推理/正文增量、最终消息替换和稳定的流式行键。原生轨迹投影测试覆盖回合分组、用户可读标签、`tool/call`/`tool/result` 关联、运行中与完成后的工具状态、受限操作预览、时长标签和传输事件隐藏。统计测试覆盖桌面兼容的吞吐规则，并拒绝原始 `132.0146174218317` 后缀。滚动策略测试覆盖跟随所有权和返回最新消息可见性。会话恢复测试覆盖同设备恢复、跨设备拒绝和已失效桌面会话拒绝。已配对的 iPhone 17 Pro 模拟器已回归权限、模式、对话、模型、待处理操作、二维码扫描、会话重命名、工作区重命名、工作区和设置页面。已检查页面显示完整多行说明、换行后的对话文本、`132 tok/s` 统计栏、预填名称和确定性的连接恢复；当前进程未再出现重复列表键警告或无效元素错误。

## Alternatives considered

**继续使用 `projectVisibleMessages()`。** 未采用，因为它的紧凑跨客户端投影刻意合并已完成的助手分块，并且只暴露用户、助手和工具记录。它适合简单转录视图，却无法表达主移动会话所需的桌面对话行差异和推流中的增量内容。

**把每一个原始事件渲染为 JSON 或无差别通用卡片。** 未采用，因为事件完整性本身不能保留桌面阅读层级。持久事件需要一个小型移动专属投影来识别关联工具、推理、重试和回合错误。

**在 WebView 中嵌入桌面/Web 对话。** 未采用，因为产品决策要求移动客户端保持原生；原生披露、滚动、可访问性、附件分享和安全区域行为必须仍由 React Native 拥有。

**复制完整桌面轨迹检查器。** 未采用，因为请求标签页、源面板、原始 JSON 和可拖拽分栏超出了移动观察任务。原生活动账本保留持久操作层级、状态、摘要和时长，而不会把手机屏幕变成调试控制台。

**只对可见吞吐字符串取整。** 未采用，因为原始事件名称和未关联的工具结果仍会使轨迹难以理解。原生投影将数值格式化和语义操作映射视为同一个可读活动界面。

## Consequences

手机对话现在以原生组件反映与桌面/Web 对话相同的持久信息类别、流式推进、读者滚动所有权、受限吞吐精度和操作级轨迹层级。新增轨迹投影仅限主移动会话，并且只从桌面事件日志派生；它不创建移动 Agent Loop、不改变桌面事件 schema，也不开放桌面专属的工具检查和文件系统控制。未来新增桌面事件类别需要作出明确的原生活动决策，不能静默落入助手 Markdown、通用工具卡片或原始协议标签。
