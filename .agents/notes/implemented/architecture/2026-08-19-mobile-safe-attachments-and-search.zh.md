# Agent Note: 移动端受限附件与内容搜索

Status: implemented

中文 | [English](2026-08-19-mobile-safe-attachments-and-search.md)

## Problem

原生客户端能够随提示上传经过压缩的照片库图片，但不能渲染桌面拥有的会话中已有的持久化图片，不能为这些已允许的图片提供系统分享/保存路径，也没有相机拍照入口，且不能跨会话搜索消息内容。既有抽屉只在本地匹配会话标题和标识，这与桌面 Web 浏览器的内容搜索行为不一致。

## Decision

Mobile Gateway 将既有 `session.search` API 暴露为已认证的 `POST /v1/sessions/search`。它验证非空搜索字符串，在联系 DSH 前拒绝 NUL 字符和超过 500 个字符的值，并原样返回桌面结果集：至多为桌面选出的内容命中，每项包含不透明会话标识、可见消息摘要和 `hasMore`。原生抽屉在编辑后等待 250 ms，在查询激活时以扁平内容命中替换分组树，在既有会话标题下显示桌面摘要，并在 `hasMore` 为真时提示用户细化查询。清空查询会恢复既有工作区树，不会创建独立的移动索引或搜索数据库。

原生消息渲染器只从普通历史事件的 `data.message.content` 数组读取图像块。对于每个已类型化的持久化图像引用，它调用既有会话范围附件路由。该路由已经委托给 `session.attachment`，其桌面实现会在返回字节和图像元数据前证明当前会话日志引用了不透明附件标识。原生客户端只接受声明的栅格媒体类型和正数图像元数据，对当前应用会话使用内存中的 React Query 结果，并且从不接收桌面路径、产物目录或任意 URL。

图像缩略图具有加载、重试和全屏预览状态。在预览中，Expo FileSystem 将已获授权的 base64 图像写入移动缓存目录，Expo Sharing 使用已验证的 MIME 类型打开操作系统分享面板。分享面板提供平台拥有的发送和保存动作；应用不会实现桌面文件系统下载路由，也不会在用户所选目标之外持久化移动副本。

编辑器保留既有的四张图片上限、JPEG 质量压缩和发送失败后草稿保留行为。其附件动作现在提供相机拍照或照片库选择。两种来源都以相同质量设置请求 base64 数据，并经过同一受限提示图像载荷，因此桌面上传失败时仍能让选定草稿保持可见以便重试。

## Alternatives considered

**代理任意桌面文件和产物。** 通用路径或产物读取会削弱 Mobile Gateway 专为会话构建的边界，并暴露桌面文件系统名称、位置和未审查内容类型。本次变更只代理桌面已对当前会话授权的持久化图像标识。

**构建移动搜索索引。** 在手机上索引全部历史会复制桌面内容、消耗存储，并使桌面删除和保留规则更难遵守。桌面 `session.search` API 已经选择可见的用户、助手和 steering 内容，并限制结果集大小。

**返回直接桌面图片 URL。** URL 会暴露主机拓扑，并让缓存和凭据处理变成客户端责任。既有的已认证 Gateway POST 路由维持配对设备凭据边界，并且只传输当前图像字节。

**将图片直接保存到共享照片库。** 直接保存需要平台特定权限策略，并会在没有用户选择目标的情况下创建另一份持久副本。原生系统分享面板让操作系统在用户明确选择后呈现标准保存或发送选项。

## Verification

Gateway 集成测试覆盖已认证的内容搜索转发、在桌面调用前拒绝 NUL 搜索输入，以及会话授权附件读取转发。移动 API 测试覆盖凭据请求头、请求体和百分号编码的会话及附件路径。Gateway 与原生应用的严格 TypeScript 检查通过，Gateway 包也成功构建。

iPhone 17 Pro iOS 26.0 模拟器在 Expo prebuild 和 Pod 安装后构建成功，链接了 ExpoFileSystem 与 Expo Sharing 使用的 Expo 模块运行时。第一个预构建后的二进制使用了陈旧的 8097 Metro 端点；Debug 预处理器现在定义 `RCT_METRO_PORT=8090`，重新安装的应用从 8090 加载已连接工作区，没有原生或 JavaScript 异常。可用的桌面状态不包含带持久化图片或内容搜索结果的已选会话，因此填充后图像预览、系统分享面板、相机拍照和搜索结果的视觉断言仍需未来的实时会话检查。

Android Debug 现在将 React Native 开发服务器和 Inspector 端口覆盖为 8090，与现有项目 Metro 服务保持一致，不影响 Release 变体或另一个占用 8081 的本地服务。Android 16 Debug APK 组装和流式 AVD 安装通过。Android 16 模拟器在干净重启前后均进入 System UI ANR，因此不能声称 Android 视觉运行时断言已完成；健康 AVD 或物理 Android 设备必须重新执行这一项检查。

## Consequences

已配对移动客户端现在可以在不本地索引的情况下搜索桌面可见会话内容，预览和分享/保存仅当前会话已授权的图片，并通过相机或照片库附加可重试的压缩照片。该功能增加 Expo Sharing 和直接 Expo FileSystem 依赖及其生成的 iOS 注册。它刻意不暴露任意桌面文件、目录、产物浏览、文本/Diff 文件下载、完整离线搜索、无限分页或自动后台媒体同步。
